# Log-analysis-
Windows Security Log Analysis project focused on detecting brute-force attacks and identifying indicators of compromise.
Summary: Investigated a series of authentication failures to determine the source and method of potential unauthorized access.

Technical Details:

Event ID: 4625 (An account failed to log on)

Logon Type: 2 (Interactive/Console)

Source Process: winlogon.exe

Conclusion: Analysis confirms multiple failed interactive login attempts. This demonstrates the system's ability to audit physical access attempts and provides the logs necessary for incident response.
